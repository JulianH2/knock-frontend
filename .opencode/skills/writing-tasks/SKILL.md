# writing-tasks

- Cada tarea cabe en un cambio pequeño y revisable.
- Cada tarea dice qué requisitos y criterios cubre.
- Todo requisito y todo criterio tiene al menos una tarea.
- Las tareas van en el orden en que se pueden ejecutar.
- El estado de cada tarea se marca: pendiente, en curso o hecha.
