# security-basics

- Valida toda entrada en la frontera y decide la autorización en el servidor.
- Mínimo privilegio y denegar por defecto.
- Sin secretos, claves ni datos personales reales en el repositorio, los registros o los prompts.
- Cada spec lista sus amenazas principales y el control que las cubre.
- Usa OWASP Top 10 y OWASP API Security Top 10 como lista mínima.
